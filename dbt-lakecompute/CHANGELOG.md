## dbt-lakecompute 0.1.0 - October 30, 2026

### Features

- Add the dbt-lakecompute adapter connection layer: auth, driver download, connection manager and schema metadata ([#2255](https://github.com/dbt-labs/dbt-adapters/issues/2255))
- Add dbt-lakecompute table materialization, column metadata, ported cross-database utility macros, and guards that fail unsupported materializations, including views, with an error naming the model. Cache newly built tables before post-hooks, enforce nested element types and struct field names in model contracts, ignore grants and persist_docs as v2 does, and find relations the schema listing misses with a targeted describe. ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
- Add dbt-lakecompute seeds: truncate or drop-and-recreate the table, then load rows as literal insert batches, matching v2. ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
- Add dbt-lakecompute incremental models: append with insert by name, and rebuild with create or replace on a first run, full refresh or insert_overwrite, matching v2. ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
