## dbt-redshift 1.11.1 - August 21, 2026

### Dependencies

- Relax the `sqlparse` upper bound from `<0.6.0` to `<0.7.0` so dbt-redshift can co-install with dbt-core, which now allows `sqlparse` 0.6.0. The floor stays at `0.5.0` so no upgrade is forced. ([#2130](https://github.com/dbt-labs/dbt-adapters/pull/2130))
