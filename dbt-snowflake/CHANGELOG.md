## dbt-snowflake 1.12.1 - September 16, 2026

### Features

- Add beta support for the Snowflake `interactive_table` materialization, covering static and dynamic (auto-refreshing) interactive tables with `target_lag`, `cluster_by`, refresh/initialization warehouses, and in-place configuration changes via ALTER where Snowflake supports it ([#1780](https://github.com/dbt-labs/dbt-adapters/issues/1780))

### Fixes

- Ignore `change_tracking=false` for Iceberg tables instead of emitting invalid DDL, since Snowflake does not allow change tracking to be turned off for Iceberg tables ([#0](https://github.com/dbt-labs/dbt-adapters/issues/0))
- Fix cluster_by, target_lag, and snowflake_initialization_warehouse change detection for dynamic tables: none of the three were normalized before comparing, causing spurious no-op ALTER statements every run (LINEAR-prefix and case for cluster_by, unit for target_lag, case for the warehouse) -- interactive tables already had this fixed ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
- Escape single quotes in identifiers interpolated into `SHOW ... LIKE` metadata queries for dynamic and interactive tables: a model whose name contained a quote terminated the SQL string literal early, so describing the relation failed or ran unintended SQL ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
- Compare a dynamic table's refresh warehouse case-insensitively when detecting configuration changes: Snowflake folds unquoted warehouse names to upper case on readback, so a desired `my_wh` compared against a reported `MY_WH` was treated as a change and fired a spurious ALTER on every run ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
- Strip double-quote delimiters from a warehouse name before comparing it case-insensitively during configuration-change detection: `SHOW` never echoes the quotes back, so a quoted `snowflake_warehouse`/`refresh_warehouse`/ `snowflake_initialization_warehouse` value never compared equal to its own readback and fired a spurious ALTER on every run ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
- Treat a single-quoted string literal inside a clustering expression (e.g. `to_char(ts, 'MON')`) as case-sensitive data during configuration-change detection: the surrounding expression text was folded correctly, but a literal's exact case, and any `)`/`,` characters embedded inside it, previously corrupted the comparison and could cause an unnecessary full refresh on every run. Live-verified against Snowflake ([#](https://github.com/dbt-labs/dbt-adapters/issues/))

## dbt-snowflake 1.12.0 - July 16, 2026

### Breaking Changes

- Add transient support for Snowflake dynamic tables via `transient` config option and `snowflake_default_transient_dynamic_tables` behavior flag. ([#716](https://github.com/dbt-labs/dbt-adapters/issues/716))

### Features

- Add COPY GRANTS support for dynamic tables to inherit object-level privileges during table creation and replacement ([#1154](https://github.com/dbt-labs/dbt-adapters/issues/1154))
- Introduction of Workload Identity Federation as a supported method of authentication to Snowflake ([#1234](https://github.com/dbt-labs/dbt-adapters/issues/1234))
- Add information on number of rows in CTAS ([#1531](https://github.com/dbt-labs/dbt-adapters/issues/1531))
- Add snowflake_initialization_warehouse parameter for dynamic tables ([#1566](https://github.com/dbt-labs/dbt-adapters/issues/1566))
- Add immutable_where parameter for dynamic tables ([#none](https://github.com/dbt-labs/dbt-adapters/issues/none))
- Add support for Snowflake Programmatic Access Token (PAT) authentication ([#1688](https://github.com/dbt-labs/dbt-adapters/issues/1688))
- Support PyPI packages for Python UDFs - when packages are specified in function config, they are templated into the CREATE statement (PACKAGES = (...)) for scalar and aggregate Python UDFs ([#1737](https://github.com/dbt-labs/dbt-adapters/issues/1737))
- Add scheduler configuration support for Snowflake dynamic tables, enabling dbt-managed refresh scheduling that is decoupled from upstream and downstream dynamic table dependencies. ([#none](https://github.com/dbt-labs/dbt-adapters/issues/none))
- Add change_tracking support for regular Snowflake tables. ([#722](https://github.com/dbt-labs/dbt-adapters/issues/722))
- Add refresh_warehouse config for Snowflake dynamic tables, allowing a separate warehouse for self-refresh independent of the DDL execution warehouse ([#1193](https://github.com/dbt-labs/dbt-adapters/issues/1193))
- Add support for `iceberg_version` config to enable Iceberg V3 table creation via model config or `catalogs.yml` `adapter_properties`. ([#1779](https://github.com/dbt-labs/dbt-adapters/issues/1779))
- Add support for the Snowflake COPY TAGS parameter in CREATE OR REPLACE TABLE, clone operations, and built-in Iceberg table creation ([#1857](https://github.com/dbt-labs/dbt-adapters/issues/1857))
- Added support for JS UDFs ([#1859](https://github.com/dbt-labs/dbt-adapters/issues/1859))
- Added support for --empty in dbt seed ([#1865](https://github.com/dbt-labs/dbt-adapters/issues/1865))
- Add `tmp_relation_type=transient` support for incremental models, enabling Snowflake lineage tracking; add `snowflake__resolve_incremental_tmp_relation` dispatch macro for controlling tmp relation destination ([#1893](https://github.com/dbt-labs/dbt-adapters/issues/1893))
- Add bridge_v2_catalog support: _v2_to_v1_type, _v2_table_format (uppercase), _translate_v2_properties (linked field map), and Capability.CatalogsV2 ([#1920](https://github.com/dbt-labs/dbt-adapters/issues/1920))
- snowflake__generate_database_name reads catalog_database from the catalog relation via build_catalog_relation; when set it takes highest priority over model database config and target.database. catalog_database is now surfaced on BuiltInCatalogRelation and IcebergRestCatalogRelation. ([#2004](https://github.com/dbt-labs/dbt-adapters/issues/2004))

### Fixes

- Enable discovering pre-existing functions by updating `list_relations_without_caching` to include function relations ([#1488](https://github.com/dbt-labs/dbt-adapters/issues/1488))
- Add override of diff_column_data_types to preserve collation while altering column ([#1258](https://github.com/dbt-labs/dbt-adapters/issues/1258))
- Fix record/replay support for cursor.stats attribute access. ([#1573](https://github.com/dbt-labs/dbt-adapters/issues/1573))
- Add cluster_by ALTER support for Snowflake dynamic tables. ([#706](https://github.com/dbt-labs/dbt-adapters/issues/706))
- equals macro now uses IS NOT DISTINCT FROM clause for comparison ([#1663](https://github.com/dbt-labs/dbt-adapters/issues/1663))
- When persist_docs.columns is enabled, dbt now warns about columns defined in YAML that don't exist in the database and filters them via the validate_doc_columns helper. ([#1690](https://github.com/dbt-labs/dbt-adapters/issues/1690))
- Fix PARTITION BY clause placement in CREATE ICEBERG TABLE DDL for Snowflake built-in catalog ([#1720](https://github.com/dbt-labs/dbt-adapters/issues/1720))
- Fix schema mismatch error for structured types (OBJECT, ARRAY, MAP) in Iceberg v3 tables by normalizing VARCHAR(134217728) to VARCHAR(16777216) ([#1721](https://github.com/dbt-labs/dbt-adapters/issues/1721))
- Use INSERT OVERWRITE to make dbt seed atomic on Snowflake, preventing concurrent readers from seeing an empty table between truncate and insert ([#740](https://github.com/dbt-labs/dbt-adapters/issues/740))
- Add regression test for unit test fixture string values being silently truncated when database column has a narrow varchar type ([#1806](https://github.com/dbt-labs/dbt-adapters/issues/1806))
- Normalize show objects results to avoid type inference edge cases ([#1826](https://github.com/dbt-labs/dbt-adapters/issues/1826))
- Fix ALTER DYNAMIC TABLE with immutable where sometimes causing a syntax error ([#1836](https://github.com/dbt-labs/dbt-adapters/issues/1836))
- Fix Python incremental `__dbt_tmp` being created as a permanent table, restore the `transient` config for Python `materialized='table'`, and accept `tmp_relation_type='table'` for Python models. ([#1928](https://github.com/dbt-labs/dbt-adapters/issues/1928))
- Add snowflake__persist_docs override and warn from snowflake__alter_column_comment so persist_docs emits the missing-column warning on Snowflake without an extra get_columns_in_relation call ([#1937](https://github.com/dbt-labs/dbt-adapters/issues/1937))
- Use SHOW USER FUNCTIONS in list_function_relations_without_caching to filter built-in functions server-side; eliminates per-schema large-result chunked S3 fetches that saturated customer-owned VPCe stage endpoints ([#1973](https://github.com/dbt-labs/dbt-adapters/issues/1973))
- Allow Workload Identity Federation (e.g. OIDC) auth to use a token without a user by exempting the workload_identity authenticator from the token/user profile validation ([#](https://github.com/dbt-labs/dbt-adapters/issues/))
