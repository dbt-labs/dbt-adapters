## dbt-athena 1.11.1 - September 07, 2026

### Features

- Add S3 Tables catalog support (catalog_type: s3_tables): register an AWS S3 Tables-backed Iceberg catalog in catalogs.yml. Set catalog_database to the federated catalog (s3tablescatalog/<bucket>) to route the model there. S3 Tables manages storage automatically, so no explicit LOCATION is emitted in DDL and direct S3 cleanup is skipped. Table replacement drops the existing table via the Glue Data Catalog (which delegates to S3 Tables), because S3 Tables does not support ALTER TABLE RENAME and Athena SQL DROP TABLE cannot target a federated sub-catalog. Supported for table, incremental, and snapshot materializations. ([#2038](https://github.com/dbt-labs/dbt-adapters/issues/2038))
